## 🚀 사용 방법

### 1단계: 토스증권 API 키 입력
폴더 내 `.env` 파일을 메모장이나 텍스트 편집기(VS Code 등)로 열고 발급받은 키를 입력합니다.
```env
TOSS_CLIENT_ID=여기에_발급받은_Client_ID_입력
TOSS_CLIENT_SECRET=여기에_발급받은_Client_Secret_입력
```
*(키를 입력하지 않은 상태에서도 공개 백업 금융 데이터를 통해 정상적으로 리포트가 생성됩니다.)*

### 2단계: 실행하기
터미널에서 아래 명령어를 실행하거나, `run.sh`를 실행합니다:
```bash
./run.sh
```

### 3단계: 결과 확인
실행이 완료되면 `reports/` 폴더 아래에 `YYYY-MM-DD_market_brief.md` 파일로 깔끔한 표와 뉴스 링크가 포함된 리포트가 저장됩니다.
